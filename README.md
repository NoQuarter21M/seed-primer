# SeedPrimer

**Physical-entropy-first BIP-39 seed generation for air-gapped machines.**

> Full README coming soon. See HARDENING.md, PICO_TRNG.md, and ADVERSARIAL_NOTES.md
> for technical documentation while this is being written.

---

SeedPrimer is a desktop GUI tool for generating BIP-39 mnemonics from
physical entropy sources — playing cards, dice, and DnD dice sets —
with optional Raspberry Pi Pico 2 TRNG injection and a full statistical
test suite to audit your physical draw before committing to a seed.

Designed to run on an air-gapped laptop. No network code. No external
dependencies beyond Python 3 and tkinter.
